4. 可由用户在已登录的 OrcaTerm 安装公钥。不要为了省这一步把密码或私钥粘到聊天。
5. 如果本机 SSH 需要用户输入密码或密钥口令，使用真实的交互终端，不把口令写进命令行、脚本、环境打印或历史。

主机身份验证：
ssh-keyscan 只能取得候选主机公钥，不能单独证明身份。
读取候选公钥的指纹，与本说明的固定 ED25519 指纹核对后，才存入本项目专用 known_hosts。

推荐连接参数：
ssh -p 22 -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes -o UserKnownHostsFile=本项目专用known_hosts路径 -i 已确认的管理员私钥路径 root@146.56.249.84

十三、API 结构与已知限制

GET /health：无鉴权健康检查。
POST /api/native/v1/session：登录。
DELETE /api/native/v1/session：撤销会话。
GET /api/native/v1/workspace：读取快照。
PUT /api/native/v1/workspace：完整快照更新。
PUT /api/native/v1/devices：登记原生 APNs 设备。
DELETE /api/native/v1/devices：注销当前用户设备。

成功结构：
{"data": ...}
错误结构：
{"error":{"code":"..."}}

常见状态：
401：未鉴权或会话过期。
409：快照版本冲突。
428：缺少 If-Match。
422：内容校验失败。

workspace GET 包含 revision 和 snapshot。
workspace PUT 的 body 为 {"snapshot": ...}，If-Match 为带引号的当前 revision。
服务端在 SQLite 事务中比较版本并更新，不能绕过这个版本保护。

snapshot 格式：
format = guangyi-native
schemaVersion = 1
records / series / activities / revisions / assets / trash 为数组
profile 包含 name、timezone
日期为带时区的 ISO 8601，原生导出含毫秒
PDF Data 为 base64

账号密码使用 scrypt。
会话有效期为 30 天，没有 refresh endpoint；过期后重新登录。
当前登录限流以连接 IP 计数，位于 Nginx 后时共享代理地址，之后可以改进但不能盲目信任客户端 X-Forwarded-For。
服务保留最近约 5 个历史快照，仍应做独立备份。
完整快照含附件时较大，未来增量同步和对象存储需要另行实现。

十七、故障处理与回退边界

1. Nginx 配置测试失败：不 reload，保留旧站点运行状态，修复本项目新增文件。

4. 后端健康失败：只处理 guangyi-workspace.service，保留 SQLite 和环境文件。
5. 代码发布失败：恢复已验证上一代码 release，只重启广益服务，不恢复或删除用户数据库。
6. 已有广益数据：备份使用 SQLite backup 或一致性快照方式，不只在运行中复制裸 .sqlite 而忽略 WAL。
7. 本机 SSH 指纹不一致：通过可信控制台核实，绝不“忽略然后继续”。
8. GitHub 密钥连接只返回受限网关报错：区分管理员身份与发布身份，不试图用发布 key 执行 shell。
9. 遇到同名文件：检查它是不是本项目已完成的一部分，不能为了让脚本通过删除整个目录。

created=0
ready=0

fail() { printf '%s\n' "$*" >&2; exit 1; }
finish() {
    local rc=$?
    trap - EXIT
    if [[ "$created" == 1 && "$ready" != 1 ]]; then
        rm -f -- "$config"
        if nginx -t; then systemctl reload nginx || true; fi
        printf '%s\n' '域名配置未完成，已移除本次新增站点；保留现有站点、广益后端、证书与数据。请发送末尾错误信息，不要发送私钥。' >&2

    exit "$rc"
}

[[ "$EUID" == 0 && -t 0 ]] || fail '请在服务器 root 网页终端运行。'
for tool in nginx certbot curl systemctl mktemp install awk flock; do
    command -v "$tool" >/dev/null || fail "缺少工具：$tool"

exec 9>/run/lock/guangyi-workspace-https.lock

[[ "$health" == '{"status":"ok"}' ]] || fail '本机广益健康检查不通过。'
if nginx -T 2>/dev/null | awk '
    /^[[:space:]]*server_name[[:space:]]/ {
        sub(/;.*/, "");
        for (i=2; i<=NF; i++) if ($i == "workspace.kdfz.com.cn") found=1;
